# 🛡️ Shopio Admin Panel (ॲडमिन पॅनेल)

स्वतंत्र ॲडमिन मॅनेजमेंट पॅनेल - युझर ॲक्सेस, सेलर मॅनेजमेंट, ऑर्डर्स, तक्रारी आणि सुरक्षा नियंत्रण.

## 📂 फाईल स्ट्रक्चर
- `index.jsx` - मुख्य ॲडमिन पॅनेल एन्ट्री पॉईंट
- `AdminPortal.jsx` - १५ सेक्शन्स असलेले संपूर्ण ॲडमिन डॅशबोर्ड कंपोनंट
- `adminService.js` - ॲडमिन डेटा आणि API स्टेट मॅनेजमेंट सर्व्हिस

## 🚀 फीचर्स
- **लाइव्ह युझर्स मॉनिटरिंग:** रिअल-टाईम युझर्स, ॲक्टिव्हिटी, डिव्हाईस आणि आयपी लोकेशन.
- **ॲप ॲक्सेस व परवानग्या:** युझर ब्लॉक/अनब्लॉक आणि नवीन युझर ॲप्रूव्हल नियंत्रण.
- **सेलर व केवायसी पडताळणी:** जीएसटी, पॅन आणि डॉक्युमेंट व्हेरिफिकेशन.
- **ऑर्डर्स व रीफंड्स:** संपूर्ण ई-कॉमर्स ऑर्डर सायकल ट्रॅकिंग.
